# Portfolio - AI & Data Science Student

A modern, professional portfolio website showcasing AI and Data Science projects, technical skills, and experience. Built with a focus on clean design, responsiveness, and user experience.

## 👋 About

This portfolio represents the work of an AI & Data Science student building real projects and learning through hands-on experience. The site is designed to showcase technical capabilities, project work, and professional growth to recruiters, potential collaborators, and mentors.

- **Skills Section**: Organized by categories:
  - Python Development
  - Machine Learning
  - Data Analysis
  - Web Development
- **Projects Section**: Three featured projects with:
  - Problem statements

### Local Development

To run the portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yuvaraj-dudukuru/my_portfolio.git
   cd my_portfolio
   ```

2. Open `index.html` in your web browser, or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   ```

3. Navigate to `http://localhost:8000` in your browser

## 🎨 Customization

### Before Deploying

1. **Update Contact Information**
   - Replace email placeholder in footer (`index.html`)
   - Add your LinkedIn profile URL
   - Update social media links

2. **Add Your Projects**
   - Replace placeholder projects with your actual work
   - Include problem statements, solutions, and tech stacks
   - Add GitHub and live demo links
   - Consider adding project images

3. **Personalize Content**
   - Update About section with your background
   - Add your profile image to `assets/img/`
   - Customize skills and descriptions

4. **SEO & Social Media**
   - Update meta tags with your information
   - Add social preview image (`assets/img/seo-img.png`)
   - Verify Open Graph and Twitter card tags

## 🚢 Deployment
