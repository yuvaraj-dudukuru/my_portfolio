# Portfolio

A modern, minimal portfolio website showcasing projects, skills, and experience.

## About

This portfolio reflects a builder mindset—focusing on real projects, practical skills, and learning through doing. Designed for recruiters, startup founders, mentors, and internship coordinators.

## Features

- Clean, modern, and professional design
- Responsive layout (mobile-first)
- Dark/Light theme toggle
- Smooth animations and interactions
- Project showcase with problem/solution format
- Skills organized by category (Core Programming, Data/AI, Web & Tools)
- Contact form integration

## Tech Stack

- HTML5
- CSS3 (with custom enhancements)
- JavaScript (Vanilla)
- GSAP (for animations)

## Customization

### TODO Items

Before deploying, make sure to:

1. **Update Contact Information**
   - Add your email in `index.html` (footer section)
   - Add your LinkedIn profile URL
   - Add your Twitter/X profile URL (if applicable)

2. **Add Projects**
   - Replace placeholder projects in `index.html` with your actual projects
   - Include: Problem statement, Tech stack, GitHub link, Live demo link
   - Add project images to `assets/img/` directory

3. **Update About Page**
   - Add your profile image to `assets/img/`
   - Update education details in `about/index.html`
   - Update experience timeline with your actual work

4. **Add Resume**
   - Upload your resume/CV and add the link in `about/index.html`

5. **Update Meta Tags**
   - Verify all meta tags and Open Graph tags reflect your information
